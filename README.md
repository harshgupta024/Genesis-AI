# Genesis AI

**Design a World. Define the Rules. Predict the Future.**

Genesis AI is an AI-powered synthetic-world simulation project designed to explore how fictional worlds evolve under configurable environmental, demographic, economic, technological, and social conditions.

## Vision

Our goal is to build an interactive platform where users can define a world, experiment with different conditions, and explore possible future scenarios using data-driven simulation and visualization.

## Key Areas

- **Synthetic World Generation:** Explore the creation of fictional worlds.
- **Environmental Simulation:** Represent environmental conditions and their potential changes.
- **Civilization Modeling:** Explore demographic, economic, technological, and social dynamics.
- **Data-Driven Predictions:** Investigate how machine learning and simulation techniques can support future-scenario analysis.
- **Interactive Visualization:** Present simulated worlds and their evolution through visual interfaces.

## Technology Stack

The current repository includes JavaScript, Vite, Three.js, and Chart.js, with Python-based data pipeline dependencies listed separately.

## Project Status

Genesis AI is under development. Features, simulation capabilities, model integrations, and deployment options should be considered experimental until implemented and tested.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/harshgupta024/Genesis-AI.git
cd Genesis-AI
npm install
npm run dev
```

To verify a production build:

```bash
npm run build
```
